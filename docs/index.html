Turn Kindle clippings into notes and quotes

Klippings reads the My Clippings.txt file from your Kindle and saves each book's highlights as its own text file, as quote images, or both. Your original file is never changed.

    Your file stays as it is

    Klippings only reads My Clippings.txt. Everything it makes is a new file in the folder you choose.

    One file per book

    Each book gets its own text file, named after the book, ready for Obsidian or any notes app.

    Download and run

    One file for Windows and Linux, one app for macOS. No installer and no account.

    One long file in. A tidy library out.

    Text files, with or without page and location

    Keep where each highlight came from, or save the words alone for your notes. The preview in the app changes as you choose.

    Quote images

    Every highlight becomes a 1080 x 1350 image in a folder named after the book. Long highlights are shared evenly across images, with fine ticks to show the order.

    Several Kindles, one library

    Open clippings from different Kindles or dated backups at once. Their books are combined, and a highlight found in more than one file is kept once.

    • Drop or choose

      Drag clippings files onto the window, or press CtrlO.

    • Pick your books

      Tick the books to export, or use Select All and Select None.

    • Read before you export

      Every book's highlights open in a reading view.

    • Leaves out the clutter

      Bookmarks, notes, article clips and empty highlights are skipped and counted.

    • Two book fonts

      Vollkorn and Platypi are built in for quote images.

    • Asks before replacing

      If a file with the same name exists, Klippings checks with you first.

    • Keyboard first

      CtrlReturn exports, arrow keys move, Space includes a book.

    • Light and dark

      The window follows your system's appearance.

    Download

    Windows .exe x64. One file: download it and run it. macOS .zip Apple Silicon. The app is unsigned, so approve it the first time under System Settings > Privacy & Security. Linux .tar.gz x64. Extract it and run Klippings.

    To run from source with Python 3.8 or later, run pip install . in the repository, then klippings.
